# Quotation prototype with n8n and Gemini

[Español](README-es.md) · [Inicio / Home](../README.md)

**Tools:** n8n · Google Sheets · Gemini API · JavaScript nodes.
**Status:** development prototype, started in 2025 and revisited in 2026.

## Challenge
Explore how customer requirements and product data could become structured quotation proposals.

## My contribution
Configured a workflow with HTTP requests, data preparation through JavaScript nodes, item-by-item processing and a Gemini call. The design includes a planned XLSX output.

## Deliverable
A workflow prototype and test screenshots documenting its stages and exposing input and model-response issues.

## Learning and scope
Tests did not produce sufficiently consistent quotations for operational use. One screenshot shows unresolved fields in the model input, identifying data mapping as an area to investigate. The issue is not attributed exclusively to the free API plan.

The workflow was not deployed to production. A complete, usable quotation export has not been established, and no savings metrics are claimed. Current work focuses on improving customer and product data structure.

The [JSON example](../02-quotation-sample.json) is a conceptual documentation structure, not a quotation generated by the prototype. Original screenshots remain private because they contain customer data.
